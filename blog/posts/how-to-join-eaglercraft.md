# How to Join Nomad Anarchy on Eaglercraft

Don't have Minecraft Java Edition? You can play Nomad Anarchy directly in your browser using Eaglercraft.

## 1. Open the Eaglercraft page

Go to the Nomad Anarchy Eaglercraft page:

**[Play Nomad Anarchy in your browser](https://nomadanarchy.online/eaglercraft)**

The game runs directly on the website, so you don't need to install Minecraft Java Edition.

## 2. Choose a version

The Eaglercraft page provides the available browser versions of the game.

Choose the version you want to play and launch it.

## 3. Join Nomad Anarchy

The Nomad Anarchy server is already configured on the Eaglercraft page, so you don't need to manually enter the server address.

Open the multiplayer/server list and select **Nomad Anarchy**.

Then connect to the server.

:::tip
If you want to get into the server quickly, use the [Nomad Anarchy Eaglercraft page](https://nomadanarchy.online/eaglercraft).
:::

## That's it

Once you're connected, you're playing Nomad Anarchy directly from your browser.

There are no normal protections, claims, or staff saving you. Build, explore, fight, or survive however you want.

## Want to use Java Edition?

You can also join from Minecraft Java Edition using:

```text
play.nomadanarchy.online
```

See the **[Java Edition joining guide](../how-to-join-java-edition/)** for the full setup.
