Play Nomad Anarchy in your browser

Eaglercraft is a port of Minecraft that runs in a web browser. You don't need to install anything. Nomad is already in the server list of each client below.

Try the WASM builds first. If WASM won't run on your browser or machine, fall back to the standard build.

version build play
Eaglercraft X 1.8.8 standard play 1.8.8 standard
Eaglercraft X 1.8.8 WASM play 1.8.8 WASM
Eaglercraft X 1.12.2 standard play 1.12.2 standard
Eaglercraft X 1.12.2 WASM play 1.12.2 WASM

If you get a blank screen or a crash, try a different build or a different browser.
