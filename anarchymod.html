Download UnblockBannedServers

We forked AnarchyMod from 6b6t and made it unblock every server on the Mojang server blacklist instead of only unblocking a specific list of servers. You don't currently need this mod to join Nomad Anarchy, but it's good to have in case we ever get blacklisted. I recommend installing it or another mod that removes Mojang's server blacklist. It works with Fabric and Legacy Fabric, runs entirely on your side, and the source code is on GitHub. You can also find it on Modrinth and CurseForge.

How to install

  1. Install the appropriate mod loader for your Minecraft version:
    • Minecraft 1.14 and newer: Fabric Loader
    • Minecraft 1.13 and older: Legacy Fabric
  2. Download the UnblockBannedServers JAR matching your Minecraft version.
  3. Place the downloaded JAR into your Minecraft mods folder.
  4. Launch Minecraft using the corresponding Fabric or Legacy Fabric profile.
  5. Join play.nomadanarchy.online.
