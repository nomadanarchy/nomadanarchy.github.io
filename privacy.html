Privacy Policy

This website

This site sets no cookies, runs no analytics, has no forms and no accounts. The only thing it stores on your device is your light/dark theme choice, saved in your browser's localStorage under the key "theme". It stays on your device and is never sent anywhere.

Hosting

The site is served by GitHub Pages, so GitHub handles requests for pages and may log visitor IP addresses and request data under its own policy. The domain's DNS is provided by Cloudflare in DNS-only mode, which means Cloudflare answers lookups for the domain but does not handle page traffic. We don't control or have access to either provider's logs.

  • GitHub privacy statement
  • Cloudflare privacy policy

Playing in the browser (Eaglercraft)

The Eaglercraft clients run in your browser and are served from this site. When you play, your browser opens a websocket connection to the game server. The client may also connect to third-party relays for LAN worlds and voice chat, which we don't run:

  • relay.deev.is
  • relay.lax1dude.net
  • relay.shhnowisnottheti.me

World data and settings from the client are stored locally in your browser.

The Discord member list

The sidebar on the home, Eaglercraft and vote pages shows who is online in our Discord server. Your browser requests this from discord.com and loads avatars from cdn.discordapp.com, so Discord receives your IP address and browser details. We don't control what Discord logs. The list shows the usernames and avatars of members who are online, which Discord publishes through the server widget setting.

Discord privacy policy.

The game server

Players on Java Edition or Eaglercraft connect directly to the game server at play.nomadanarchy.online, which is separate from the website and is not behind Cloudflare or GitHub.

The server logs anything that PaperMC 1.12.2, PaperMC 26.2, and Velocity log, which includes IP addresses, usernames, chat messages, and commands. Logs are kept forever.

The game server is hosted by Oracle. Oracle privacy policy.

Other sites

YouTube, Instagram, TikTok, and the server list sites linked from the vote page are third parties with their own policies.
