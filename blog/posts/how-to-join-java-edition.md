# How to Join Nomad Anarchy on Java Edition

Joining Nomad Anarchy on Minecraft Java Edition only takes a few seconds.

## 1. Open Minecraft Java Edition

Launch **Minecraft: Java Edition** using the Minecraft Launcher.

Nomad Anarchy runs on Minecraft **1.12.2**, with compatibility for supported newer and older versions 1.7.10 all the way up to the latest.

## 2. Open Multiplayer

From the Minecraft main menu:

1. Click **Multiplayer**.
2. Click **Add Server**.
3. Enter a name, such as `Nomad Anarchy`.
4. Enter this server address:

```text
play.nomadanarchy.online
```

5. Click **Done**.

## 3. Join the server

Select **Nomad Anarchy** from your server list and click **Join Server**.

That's it. You're in.

:::tip
Save the server to your multiplayer list so you don't have to enter the address again.
:::

## Server Address

The Java Edition address is:

```text
play.nomadanarchy.online
```

Nomad Anarchy is an anarchy server — there are no normal protections or staff coming to save you.
